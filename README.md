## Основные результаты

1. Годовая амплитуда температуры превышает **63 °C** (от −32.5 до +30.9) —
   резко континентальный климат Предуралья.
2. Амплитуда суточного хода летом **7.2 °C** против **2.3 °C** зимой — следствие
   различий в радиационном балансе.
3. Связь температуры и влажности **меняет знак в зависимости от масштаба**:
   внутри суток r ≈ −0.90 (июль), зимой на межсуточном масштабе r ≈ +0.41.
   Слабая корреляция по всему ряду (−0.27) возникает из-за смешения механизмов.
4. Точность методов восстановления различается более чем на порядок:

   | Метод | Средняя абсолютная ошибка |
   |---|---|
   | Локальный Лагранж, k = 4 | **0.251 °C** |
   | Кубический сплайн | 0.361 °C |
   | Локальный Лагранж, k = 6 | 0.754 °C |
   | Среднее 3 предыдущих | 1.494 °C |
   | Медиана | 2.571 °C |
   | Среднее | 2.968 °C |
   | Глобальный Лагранж (23-я степень) | ~9.4·10⁴ °C |

5. Глобальный многочлен Лагранжа неприменим из-за **эффекта Рунге**; увеличение
   числа узлов в локальной схеме с 4 до 6 **ухудшает** результат втрое —
   решающее значение имеет умеренность степени многочлена, а не объём данных.
6. Распределение температуры за год не является нормальным: вне 2σ оказалось
   3.7 % значений при ожидаемых 4.6 %, вне 3σ — ни одного при ожидаемых 0.3 %.

# Задание 2

**Регрессионный анализ: использование экстраполяции в задачах прогнозирования
значений временных рядов**

Ноутбук — [`notebooks/hw2_perm_forecast.ipynb`](notebooks/hw2_perm_forecast.ipynb),
собирается скриптом `scripts/build_notebook_hw2.py`.

## Постановка

Прогнозируемый параметр — температура воздуха. Взято **120 последовательных
часовых значений** (1—5 июля 2024), разбитых на **96 обучающих (80 %)** и
**24 тестовых (20 %)**. Длина кратна суткам, чтобы тестовая выборка содержала
ровно один полный суточный цикл. Горизонт прогноза — 24 шага, ни одно тестовое
значение моделям не показывается.

Гиперпараметры (k, C, ε, alpha, число компонент) подбираются на внутренней
проверочной части обучающей выборки — тест в подборе не участвует.

## Соответствие пунктам задания

| Пункт | Раздел ноутбука | Результат |
|---|---|---|
| 1. 100+ значений, разбиение 80/20 | 1 | 120 значений: 96 / 24 |
| 1а. ARIMA | 2 | Порядок по AIC, сезонный и несезонный варианты |
| 1б. k-NN / скользящее среднее | 3 | `hw2_03_knn.png` |

| 3. Модель с двумя параметрами | 5 | Второй параметр — влажность, прогнозируется отдельно |
| 4. Графики всех моделей с выборками | 2—8 | 11 рисунков `figures/hw2_*.png` |
| 5. Сравнение по MAE, RMSE, выводы | 6, 9 | Сводные таблицы |

## Основные выводы

1. **Качество определяется не сложностью метода, а доступом к информации о
   суточном цикле.** Модели выше черты имеют его в том или ином виде (сезонный
   лаг, влажность в противофазе, гармоники суток), модели ниже — нет. Нелинейный
   SVR на времени проигрывает обычному МНК на двух параметрах.
2. **Экстраполяция ≠ интерполяция.** SVR с RBF-ядром точно описывает обучающий
   интервал и вырождается в константу сразу за его границей: точки прогноза
   далеки от всех опорных векторов, ядровые функции затухают.
3. **Рекурсивная схема накапливает ошибку.** Скользящее среднее через k шагов
   перестаёт содержать в окне реальные наблюдения и застывает; величина k на это
   не влияет.
4. **Многопараметрическая модель требует прогноза каждого параметра.** Влажность
   на горизонте неизвестна, её прогноз (MAE 6.3 %) вносит свою ошибку — но
   информация о фазе цикла эту плату окупает.
5. **Больше данных — не значит лучше.** Удвоение обучающей выборки (96 → 192 ч)
   ухудшило прогноз с MAE 1.66 до 3.49 °C: ряд нестационарен, средний уровень за
   8 суток до теста равен 18.3 °C против 25.4 °C в тестовые сутки, и ARIMA тянет
   прогноз к этому заниженному среднему.
6. **МНК по 24 лагам сопоставим со специализированной ARIMA** (MAE 2.64), тогда
   как тот же МНК по 1 и 3 лагам даёт плоскую линию — решает состав регрессоров,
   а не метод обучения.
